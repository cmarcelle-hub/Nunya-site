

## Plan : Générer un prompt reproductible du site NUNYA

Je vais créer un fichier texte contenant un **prompt complet et détaillé** que vous pourrez copier-coller dans n'importe quel outil IA (ChatGPT, Claude, Lovable, Cursor, etc.) pour reconstruire ce site à l'identique.

Le prompt inclura :

1. **Stack technique** : React 18 + Vite + Tailwind CSS + Framer Motion + React Router
2. **Design system** : palette terre cuite/forêt/or/sable, polices Playfair Display + DM Sans, variables CSS HSL complètes
3. **Architecture** : 6 routes, composants Navbar/Footer/Hero/Impact partagés
4. **Contenu exact** de chaque page : textes, placeholders, structure des sections
5. **Navigation** : onglets, sous-menu "Nos actions" (Togo/RDC), CTA "Faire un don"
6. **Footer** : partenaires + liens réseaux sociaux (HelloAsso, Facebook, Instagram)
7. **Contraintes** : responsive, animations, ton rédactionnel

Le fichier sera exporté en `.md` dans `/mnt/documents/` pour téléchargement.
